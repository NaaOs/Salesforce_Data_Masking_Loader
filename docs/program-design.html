1. 概要

1.1 目的

本プログラムは、CSV ファイルに含まれる個人情報・機密情報を YAML で定義したルールに従ってダミーデータに置き換え（マスキング）、その結果を CSV として出力する、または Salesforce の SOAP Partner API を用いて Insert / Upsert するツールである。主に検証用 Sandbox へ本番相当のデータを安全に投入する用途を想定している。

1.2 機能一覧

No機能概要担当クラス
F01マスキング設定読込YAML（UTF-8）を読み込み、オブジェクト／項目ごとのマスキングルールを生成し、タイプ別の制約も含めて妥当性を検証するConfigLoader
F02CSV 読込・マスキングCSV（UTF-8、BOM 可）をチャンク単位で読み込み、設定対象項目をダミー値に置換する。列順は保持するCsvProcessor / MaskingDataGenerator
F03マスキング済み CSV 出力（mask-only）マスキング結果を {オブジェクト名}_masked_{yyyyMMdd_HHmmss_SSS}.csv にストリーミング出力するMaskingService / CsvProcessor
F04Salesforce Insert（mask-insert）マスキング結果をバッチ単位で create() するMaskingService / SalesforceConnection
F05Salesforce Upsert（mask-upsert）外部 ID 項目をキーにバッチ単位で upsert() するMaskingService / SalesforceConnection
F06投入エラー出力Insert / Upsert で失敗したレコードを行番号・エラー内容付きで {オブジェクト名}_errors_{…}.csv に出力し、成功・失敗件数を通知するMaskingService
F07CLI 実行引数付きで JAR を実行すると、処理モード・オブジェクト・CSV を指定して一括実行し、結果を終了コードで返すLauncher / DataMaskingLoader
F08GUI 実行引数なしで JAR を実行すると JavaFX 画面を起動し、非同期処理・件数ベースの進捗表示・ログ表示を行うLauncher / DataMaskingApp / MainController

2.3 アーキテクチャ

プレゼンテーション層（CLI / GUI）は入力の受付と結果表示のみを担い、処理本体はサービス層の MaskingService に集約する。MaskingService は CSV をチャンク単位で読み込み、マスキングしたものをすぐに CSV 出力または Salesforce 投入へ渡すため、全レコードをメモリに保持しない。Salesforce への投入は SalesforceClient インタフェース経由で行い、テストではフェイク実装に差し替える。

エントリポイント:

  • 実行可能 JAR: com.salesforce.tools.Launcher（pom.xml の Main-Class）。引数なしで GUI、引数ありで CLI。Application を継承しないクラスから JavaFX を起動するため、依存込み JAR を java -jar で直接実行できる。
  • 開発時の GUI 起動: mvn javafx:run（mainClass は DataMaskingApp）

MaskingServicecom.salesforce.tools.serviceサービス

CLI / GUI 共通の処理本体。コンストラクタで CsvProcessor と SalesforceClient の生成関数を受け取れる（既定は CsvProcessor::new / SalesforceConnection::new）。

定数

名前値説明
CSV_CHUNK_SIZE1000mask-only 時のチャンク件数
BATCHES_PER_CHUNK10Salesforce 投入時のチャンク件数 = batchSize × 10

execute(ProcessRequest, ProgressListener): ProcessResult

  1. オブジェクト設定の存在確認（なければ IllegalArgumentException）、入力 CSV の存在確認（なければ IOException）、出力先ディレクトリの作成
  2. countRecords() で総件数を取得（進捗率の分母）。0 件なら件数 0 の結果を返す
  3. mask-only: processInChunks() で 1,000 件ずつ受け取り、最初のチャンクで出力ファイルを開いて順次書き込む
  4. mask-insert / mask-upsert:
    1. SalesforceConfig.load() → SalesforceClient 生成 → connect()
    2. batchSize×10 件ずつ受け取り、insertRecords / upsertRecords を呼ぶ
    3. 失敗した RecordResult は、最初の失敗時に開いたエラー CSV へ RowNumber（チャンク先頭行番号＋index）、Error、マスキング後の値を書き込む
    4. ConnectionException 発生時は、それまでの件数を持つ ProcessingException を送出（メッセージに未処理の開始行を含む）
    5. try-with-resources で必ず close()（ログアウト）
  5. 各チャンク処理後に ProgressListener.onProgress(割合, "n / total 件処理（成功 x 件、失敗 y 件）") を通知

進捗率

0%「件数確認中」→ 5%「n 件のレコードを処理します」→（Salesforce 時）5%「接続中」→ 8%「Insert/Upsert 実行中」→ 処理件数に比例 → 100%「処理完了」または「完了（失敗 n 件あり）」。

CsvProcessorcom.salesforce.tools.csv

コンストラクタで MaskingDataGenerator と文字コード（既定 UTF-8）を受け取る。レコードは列順を保持する LinkedHashMap で表現する。

シグネチャ処理内容
public int countRecords(String csvPath)ヘッダーを除くデータ件数を数える（クォート内の改行を正しく扱う）
public int processInChunks(String path, ObjectConfig cfg, int chunkSize, ChunkHandler handler) throws Exception
  1. ヘッダー読込。先頭の BOM を除去し、各列名を trim
  2. 列ごとの FieldConfig を事前に解決
  3. データ行ごとに、設定ありの列はダミー値、設定なしの列は元値（列不足は空文字）で LinkedHashMap を作成
  4. chunkSize 件ごと、および最後の端数で handler.handle(headers, chunk, 先頭行番号) を呼ぶ
  5. CsvValidationException は IOException("CSVフォーマットエラー: …") に変換
戻り値は処理件数。マスキング後の値はログに出さない
public RecordWriter openWriter(String path, List<String> headers)ヘッダーを書き込んだ状態のライターを返す。RecordWriter.write(Map) / write(List) はヘッダー順に値を出力（null は空文字）
public List<Map> readAndMaskCsv(String path, ObjectConfig cfg)全件をリストで返す（小規模データ・テスト向け）
public void writeMaskedCsv(String path, List<Map> records)先頭レコードのキー順（＝入力列順）で全件出力

Random を受け取るコンストラクタを持ち、同じ乱数を Faker(Locale.JAPAN, random) と英数字生成にも使う（シードを固定すれば再現できる）。generateMaskedValue(FieldConfig) は MaskingType に応じた値を返し、引数が null の場合と生成中に例外が出た場合は null を返す。各タイプの生成方法は 7. マスキング仕様 を参照。

7. マスキング仕様

MaskingType生成ロジックパラメータ出力例
RANDOM_STRING英大小文字・数字からランダムに length 文字length 1〜255（既定 20）aZ3k9QwP0mLx7Rt2YbN1
PHONE"090-%04d-%04d" に 0〜9999 の乱数 2 つ-090-0427-8815
EMAILfaker.internet().emailAddress()-ロケール依存の文字列＠ダミードメイン
FIRST_NAMEfaker.name().firstName()-翔太
LAST_NAMEfaker.name().lastName()-佐藤
ADDRESSfaker.address().fullAddress()-ロケール依存の住所文字列
COMPANY_NAMEfaker.company().name()-ロケール依存の会社名
FIXED_VALUE設定値をそのまま返すvalue（必須）MASKED
NUMBERlong 型の乱数を 10length で剰余 → 0〜10length−1length 1〜18（既定 10）48213
DATEfaker.date().birthday() を yyyy-MM-dd で整形（18〜65 歳相当）-1987-04-12

共通仕様

  • 元の値は参照せず、毎回独立した乱数で生成する（同じ元値でも結果は一致しない）。
  • 元の値が空欄でも、設定対象の項目にはダミー値を設定する。
  • 設定にない列は元の値のまま出力・投入する。ただし Salesforce 投入時、空文字の項目は送信しない。
